# DemoTracer logo

These SVG files are the canonical DemoTracer mark. Their canvas is transparent;
no screenshot background, shadow, or glow belongs to the logo.

- `demotracer-logo-color.svg` — primary product mark
- `demotracer-logo-grayscale.svg` — grayscale reproduction
- `demotracer-logo-black.svg` — single-color black mark with a transparent monogram
- `demotracer-logo-white.svg` — single-color white mark with a transparent monogram

Keep the circle, `DT` monogram geometry, and 1024 × 1024 view box aligned across
all variants. Use the color mark for the application, installer, favicon, and
normal product presentation. Use the black or white mark only when production
constraints require one color.
