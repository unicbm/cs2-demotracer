# Shared contracts and data

This area contains small, versioned artifacts consumed across product
boundaries.

| Path | Responsibility |
| --- | --- |
| [`contracts/`](contracts/) | Desktop/server release and ABI compatibility contracts |
| [`econ/`](econ/) | Generated cross-runtime projection of the pinned `@ianlucas/cs2-lib` catalog |

Keep this directory limited to artifacts that genuinely have multiple
consumers. Product-specific source belongs under `desktop/` or `server/`.
The econ projection is generated by
[`tooling/cs2-lib-data/generate-econ-index.mjs`](../tooling/cs2-lib-data/generate-econ-index.mjs)
directly from the exact npm dependency and must never be hand-maintained.
